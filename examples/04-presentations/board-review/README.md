# A quarterly board review

**Tool:** Presentation tools · **How you reach it:** Chat message

## The situation
The quarterly review needs the numbers and the plan in a tidy deck. You have the data, not the time.

## What you ask the agent
```text
Build a quarterly review deck: results, highlights, challenges, and next quarter plan.
```

![A quarterly review presentation slide](img/board-review.png)

## What AgentBridge does
The agent assembles the review deck with the results, the wins, the issues and the plan — laid out so the meeting moves quickly.

## Good to know
Attach your KPI sheet and the agent puts the charts in the slides.
