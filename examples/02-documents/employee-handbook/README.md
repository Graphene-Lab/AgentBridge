# A simple staff handbook

**Tool:** Office document tools · **How you reach it:** Chat message

## The situation
Your small team keeps asking the same questions. A short handbook answers them once, for everyone.

## What you ask the agent
```text
Write a short employee handbook covering working hours, holidays, remote work rules and who to ask for help.
```

![A friendly staff handbook, ready to share](img/employee-handbook.png)

## What AgentBridge does
The agent writes a clear, friendly handbook in plain language, with each topic on its own page. Update it any time by asking — 'add a line about the new parking rule'.

## Good to know
Keep it in your documents area so the agent can answer questions from it later.
