# Make an invoice in seconds

**Tool:** Document tools (OfficeSupport) · **How you reach it:** Chat message

## The situation
You finished a job for a client and need a clean invoice. Normally you open a template, type the lines, fix the totals. Today you just ask.

## What you ask the agent
```text
Make an invoice for Bright Cafe for 12 hours of bookkeeping at 45 euros an hour, due in 14 days.
```

![A finished invoice document produced by the agent](img/client-invoice.png)

## What AgentBridge does
The agent writes a proper invoice with your business details, the line items, the subtotal, tax and total, and a due date. You get a real document you can print or send. If a number is wrong, you say so and it fixes it.

## Good to know
Ask for it as a real Word file (/tools office-files) if you want to keep editing it in Microsoft Office.
