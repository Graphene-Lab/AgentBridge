# Turn an idea into a proposal

**Tool:** Document tools · **How you reach it:** Chat message

## The situation
A potential client asked for a written proposal. You have the ideas in your head but no time to lay them out.

## What you ask the agent
```text
Create a project proposal for a small online shop: goals, what we deliver, timeline of 8 weeks, and a price of 9,500 euros.
```

![A structured project proposal document](img/project-proposal.png)

## What AgentBridge does
The agent builds a proposal with the client's goal, your solution, the deliverables, the timeline and the price — all in a clean layout that looks like it took a whole afternoon. It took a minute.

## Good to know
Add your logo and a sentence about past results to make it feel personal.
