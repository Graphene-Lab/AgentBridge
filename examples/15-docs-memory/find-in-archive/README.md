# Find that old document

**Tool:** Documents area (index) · **How you reach it:** Chat message

## The situation
You know you wrote something about this last year but cannot find the file.

## What you ask the agent
```text
Find the proposal I sent to the hotel last spring about the lobby redesign.
```

![A search through your indexed archive](img/find-in-archive.png)

## What AgentBridge does
The agent searches your indexed archive and brings back the document you meant, even when you only half-remember it.

## Good to know
The index updates as you add files, so the archive is always current.
