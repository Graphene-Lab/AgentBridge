# Nothing is ever lost

**Tool:** Version history (Git) · **How you reach it:** Chat message

## The situation
You changed a document and want the earlier version back.

## What you ask the agent
```text
Show me the previous version of the contract and restore it.
```

![Version history lets you go back safely](img/version-history.png)

## What AgentBridge does
Every version the agent made is kept. You can see the earlier draft and bring it back, so editing is always safe.

## Good to know
This is why you can let the agent rewrite things freely — the history protects you.
