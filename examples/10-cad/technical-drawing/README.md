# A drawing for the workshop

**Tool:** CAD tools (FreeCAD) · **How you reach it:** Chat message

## The situation
The workshop needs a drawing with dimensions to make the part.

## What you ask the agent
```text
Produce a technical drawing of the bracket with the key dimensions marked.
```

![A dimensioned technical drawing for production](img/technical-drawing.png)

## What AgentBridge does
The agent generates a drawing with the dimensions marked, ready for the person who will make the part.

## Good to know
Ask for the view you need — top, side — so the drawing is clear.
