# Give the agent a document to read

**Tool:** Attachments (@ / files) · **How you reach it:** Terminal window

## The situation
You want the agent to work with a file you already have — a supplier list, a contract draft, a report. You attach it to the chat.

## What you ask the agent
```text
@  (then pick the file)
```

![The @ palette: choose an uploaded file to attach to your message](img/attach-file.png)

## What AgentBridge does
The file is attached to your message. The agent reads it and answers using its real contents — summarising it, checking it, or building something new from it. Nothing leaves your machine except what you choose to send to the AI.

## Good to know
You can attach several files at once. The agent keeps them for the conversation, so you can ask follow-up questions.
