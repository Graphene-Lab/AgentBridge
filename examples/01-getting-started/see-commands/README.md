# Every command in one place

**Tool:** Help (F1) · **How you reach it:** Terminal window

## The situation
You forgot how to upload a file. Instead of searching the internet, you open the built-in help and read the short list.

## What you ask the agent
```text
F1
```

![The help screen lists every command with a one-line explanation](img/see-commands.png)

## What AgentBridge does
The help screen shows the commands and what each one does: /files to upload, /model to switch AI, /email to set up mail, and more. It closes with one key. No manuals, no googling.

## Good to know
Typing / opens a live list that filters as you type, so you often do not need the full help screen at all.
