# Connect other AI tools to it

**Tool:** MCP connector · **How you reach it:** Developer / MCP

## The situation
You use other AI tools that speak the MCP standard. AgentBridge can act as their connector.

## What you ask the agent
```text
(MCP) Connect AgentBridge as a tool server.
```

![AgentBridge connected to other AI tools via MCP](img/mcp-connector.png)

## What AgentBridge does
Other AI applications can use AgentBridge's tools through the MCP standard, so your whole toolkit works together.

## Good to know
MCP is for connecting tools; for everyday use the chat is all you need.
