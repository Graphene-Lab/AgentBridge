# See all your agents at a glance

**Tool:** OfficeManager · **How you reach it:** Browser

## The situation
You run several agents and want one simple view of what each is doing.

## What you ask the agent
```text
(browser) Open the OfficeManager view.
```

![The OfficeManager view of your agents](img/officemanager-view.png)

## What AgentBridge does
OfficeManager shows your agents in one simple page, so you can see what is running and where things stand.

## Good to know
A quick way to keep an eye on more than one assistant at once.
