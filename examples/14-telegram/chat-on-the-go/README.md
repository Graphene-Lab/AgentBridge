# Your assistant in Telegram

**Tool:** Telegram · **How you reach it:** Telegram chat

## The situation
You already live in Telegram. Your assistant joins you there, so you ask things the same way.

## What you ask the agent
```text
(telegram) How much did we sell yesterday?
```

![A conversation with the agent inside Telegram](img/chat-on-the-go.png)

## What AgentBridge does
The agent answers in your Telegram chat, just like a colleague. Ask a question, get the answer, keep moving.

## Good to know
Telegram access uses an allow-list, so only the people you choose can talk to it.
