# Plan a delivery route

**Tool:** Map tools · **How you reach it:** Chat message

## The situation
You have several drops today and want a sensible route that saves driving time.

## What you ask the agent
```text
Plan the best route for these five delivery addresses and show it on a map.
```

![A delivery route mapped across the stops](img/delivery-route.png)

## What AgentBridge does
The agent plots the stops on a map in an efficient order and gives you the distance and estimated time. You follow the route and save fuel.

## Good to know
Add time windows ('stop B before noon') and the agent factors them in.
