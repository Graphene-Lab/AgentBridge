# Draw your service area

**Tool:** Map tools · **How you reach it:** Chat message

## The situation
You want to show customers the area you cover, so there is no confusion about delivery.

## What you ask the agent
```text
Show our service area on a map with the main towns we cover.
```

![A service-area map for customers](img/service-area.png)

## What AgentBridge does
The agent produces a clear map of your coverage that you can put on your website or send to customers.
