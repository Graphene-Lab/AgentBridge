# A report that writes itself each morning

**Tool:** Scheduled tasks · **How you reach it:** Agreed schedule

## The situation
You want the same report every morning without remembering to ask for it.

## What you ask the agent
```text
Every weekday at 8am, give me a summary of yesterday's sales and any urgent emails.
```

![A scheduled task set up to run each morning](img/daily-report.png)

## What AgentBridge does
The agent runs the report on its own each morning and has it waiting for you. You agreed the time once; it never forgets.

## On a schedule
This is a recurring task. AgentBridge starts it at the agreed time and delivers the result to your chat, your email or your phone.

## Good to know
You can change or stop a scheduled task any time by telling the agent.
