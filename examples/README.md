# AgentBridge — example library

Real, plain-English examples of how a non-technical person automates office work with
**AgentBridge**. Each example is a small folder with a short story (`README.md`) and one
clear picture (`img/*.png`) of the finished result.

There are **63 examples** covering every tool and channel: documents, spreadsheets,
presentations, PDF reports, email, web research, maps, ERP, CAD, podcasts, scheduled
tasks, voice and phone, Telegram, your own documents and memory, and the web/API.
