AgentBridge is a self-hosted server that runs AI agents with two interfaces in a single process: a full-screen chat terminal (TUI) and a standard HTTP API compatible with OpenAI, plus a native MCP connector. It automates office work — documents, spreadsheets, email, presentations, web research — while keeping your data on your machine inside an application-level sandbox. Runs on Windows, Linux and macOS; works with local models (Ollama, ExLlamaV2) or cloud providers (DeepSeek, Z.ai, Gemini, Anthropic) with GDPR-ready anonymization. Reachable 24/7 via SIP phone and Telegram.

Frequently asked questions

Which platforms does AgentBridge support?

Windows 64-bit, Linux x64, Linux ARM64 (Raspberry Pi, etc.), macOS Intel and macOS Apple Silicon. Each archive is self-contained (~460 MB) and needs no .NET installation; the Kokoro TTS voices are included.

Does AgentBridge work offline?

Yes. With a local model (Ollama, ExLlamaV2 or a local bridge) nothing leaves your machine. With a cloud provider, only the model call leaves — optionally protected by GDPR-ready anonymization.

Is AgentBridge free?

The download is free and the source is released for personal use under the Andrea Bruno License 1.4; commercial use of the code requires a royalty agreement with the author.
